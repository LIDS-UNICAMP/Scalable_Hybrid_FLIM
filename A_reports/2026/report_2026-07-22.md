# Avaliação de cabeças de classificação sobre o encoder FLIM

**Data:** 2026-07-22 · **git:** `bdbadc2` · **Gerado por:** pipeline de avaliação (Claude Code)

Comparação de **três cabeças de classificação** sobre o **mesmo encoder FLIM**
(inicializado com pesos FLIM pré-treinados), em **1%** e **75%** de dados de
treino, nos datasets `eggs`, `larvae` e `protozoan` (3 splits cada):

- **SVM + FLIM** — SVM linear sobre embeddings do encoder FLIM congelado.
- **FLIM + MLP (ReLU)** — MLP com ativação ReLU, frozen e unfrozen.
- **FLIM + MLP (Sigmoid)** — cabeça 2-layer Sigmoid (modelo `sigmoid2l_`), frozen e unfrozen.

---

## 1. Caracterização do modelo `sigmoid2l_` (braço FLIM + MLP Sigmoid)

**Arquitetura** (`src/modules/classification_flim_module.py`, `src/models/models.py:351`):

```
entrada (3×200×200, LAB, ift_lab, imagenet_norm=True)
  │
  ├─ Encoder FLIM (3 blocos conv, init = pesos FLIM pré-treinados)
  │     conv1: Conv2d(3→24, 5×5)  + ReLU + MaxPool(3×3, s2)
  │     conv2: Conv2d(24→32, 5×5) + ReLU + MaxPool(3×3, s2)   (protozoan: 24→30)
  │     conv3: Conv2d(32→48, 5×5) + ReLU + MaxPool(3×3, s2)   (protozoan: 30→48)
  │
  └─ TwoLayerSigmoidHead
        AdaptiveAvgPool2d(1) → Linear(48,24) → Sigmoid → Linear(24,C) → Softmax
```

| Item | Valor |
|:--|:--|
| **Inicialização — encoder** | Pesos **FLIM pré-treinados** carregados do disco (`load_FLIM_encoder`), de `data/to_mateus/model/ch24_32_48_a0.5_f5/<dataset>/train<split>/models`. Por design é FLIM-init only (`ENCODER_INITS=("flim",)`). |
| **Inicialização — head** | Init **default do PyTorch** para `nn.Linear` (Kaiming-uniform); não há init explícito no head. |
| **hidden_dim** | 24 (= encoder_out // 2 = 48 // 2) |
| **Loss de treino** | `NLLLoss` sobre `log(softmax_probs)` — `F.nll_loss(torch.log(probs.clamp_min(1e-12)), labels)`; equivale a CrossEntropy, mas o head já aplica Softmax (`classification_flim_module.py:176`). |
| **Freeze** | Os 18/18 runs `sigmoid2l_` "canônicos" são **`freeze_encoder=false`** (treino end-to-end encoder+head). Existe também a variante `--freeze-encoder` (congela `model.encoder`, treina só o head) — os diretórios `_frozen`. Ambas são reportadas na comparação. |
| **Otimização** | AdamW, `lr=5e-4`, `weight_decay=5e-2`, `max_epochs=100`, `warmup_epochs=10`, `batch_size=32`, seed=42. |

**Contagem de parâmetros** (dos checkpoints reais, deduplicando os aliases `blocks.*`):

| Dataset (C) | conv1 | conv2 | conv3 | Encoder | Head (L1=1176 + L2) | **Total** |
|:--|--:|--:|--:|--:|--:|--:|
| eggs (9) | 1 824 | 19 232 | 38 448 | 59 504 | 1 401 | **60 905** |
| larvae (2) | 1 824 | 19 232 | 38 448 | 59 504 | 1 226 | **60 730** |
| protozoan (7) | 1 824 | 18 030 | 36 048 | 55 902 | 1 351 | **57 253** |

> `protozoan` usa `PROTOZOAN_FLIM_ARCH` (canal intermediário 30, não 32). Todos os conv são 5×5.
> Head: `Linear(48,24)` = 1 176 params; `Linear(24,C)` = 25·C params.

## 4. Comparação das três cabeças

### 4.1 Definição das colunas

- **Dataset** — parasita avaliado (`eggs`, `larvae`, `protozoan`/cistos).
- **Cabeça de classificação** — o classificador sobre o encoder FLIM: `SVM + FLIM`, `FLIM + MLP (ReLU)` ou `FLIM + MLP (Sigmoid)`.
- **Modo do encoder** — `frozen` (encoder FLIM congelado; só a cabeça treina) ou `unfrozen` (fine-tune end-to-end encoder + cabeça). SVM só tem `frozen` (não faz backprop).
- **n (splits)** — número de splits agregados na média.
- **Test Accuracy (média ± dp)** — acurácia no conjunto de **teste**, média ± desvio-padrão amostral sobre os splits.
- **Test F1-weighted (média ± dp)** — F1 ponderado por suporte de classe (`test_f1_weighted`) no conjunto de **teste**, média ± desvio-padrão amostral sobre os splits.
- **Test Cohen κ (média ± dp)** — Cohen's kappa no conjunto de **teste**, média ± desvio-padrão amostral sobre os splits.

Em cada dataset, **o melhor valor de cada métrica está em negrito**.
