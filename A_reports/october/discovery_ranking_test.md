O κ (kappa) é a nota do juiz: 1 é perfeito, 0 é chute. O I-JEPA fica sempre no topo como régua: quem tem Δ positivo passou dele. A escolha do melhor é feita só na validação; o teste aparece aqui só para reportar.

## Como ler

- **Leitura (readout)** = como o mapa de features da camada vira um vetor para o SVM:
  - `avgpool2d`: a média de cada canal (um número por filtro). L4 com 1280 canais → 1280-d.
  - `gem`: média generalizada com p=3 — parecida com a média, mas dá mais peso aos pontos mais fortes.
  - `gem_dense`: GeM da L3 + GeM da L4 colados (64 + 1280 = 1344-d).
  - `gem_fg` / `avgpool2d_fg`: igual, mas só nos pixels do objeto (sem fundo).
  - `spp`: pirâmide de poolings (grades 1×1, 2×2, 4×4) colada; `flatten`: o mapa inteiro achatado (vetor enorme).
- **Camada** `L1…L8` = até onde a rede cresceu quando o SVM leu.
- **Seleção é sempre na validação.** O κ de val escolhe camada/leitura/checkpoint; o κ de teste só reporta.
- `(n)` = nº de splits com resultado; `pendente` = ainda sem CSV de teste. Desvio padrão é amostral (n−1).
- Links W&B: run id do `ckpt_dir` do `run_metadata.json` (split 1, camada mais funda); projeto lido do arquivo `.wandb` local; entity `ophira-ai` vem de `WANDB_ENTITY` em `experiments/constants.py` (o arquivo local não grava a entity).
